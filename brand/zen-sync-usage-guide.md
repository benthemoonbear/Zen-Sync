# Zen Sync — logo usage guide

**The mark:** a brush-drawn ensō (Zen circle) with one dot resting in its opening — the moment every camera lines up.
**Name:** always "Zen Sync" — two words, capital Z and S. Descriptor where space allows: "Zen Sync — wedding photo sorter".

## Versions
| Use | File |
|---|---|
| Main (light backgrounds) | `zen-sync-horizontal-black.svg` |
| Dark backgrounds | `zen-sync-horizontal-mono-f3e3c3.svg` (gold) or `-white.svg` |
| Square spaces | `zen-sync-stacked-*.svg` |
| Symbol only (icons, avatars, watermark) | `zen-sync-symbol-*.svg` |
| App icon (glow) | `zen-sync-app-icon.svg`, `app-icon/zen-sync-app-icon-1024.png` |
| Website | `favicon.ico`, `favicon.svg`, `icon-192/512.png`, `apple-touch-icon.png`, `site.webmanifest`, paste `head-snippet.html` |

## Colour
| Name | HEX | RGB | Use |
|---|---|---|---|
| Champagne gold | `#F3E3C3` | 243 227 195 | the mark on dark; highlights |
| Dot light | `#FFF4DE` | 255 244 222 | the dot on dark / glowing versions |
| Deep gold | `#E9C98E` | 233 201 142 | liquid-fill loader, accents |
| Near-black | `#151517` | 21 21 23 | backgrounds, app icon tile |
| Ink | `#000000` | 0 0 0 | the mark on light backgrounds |

**Glow:** only on dark backgrounds (app icon, start screen, website hero, social graphics). Never on light backgrounds, in print, or below 48 px — use the flat mark there.

## Type
Wordmark: Inter Display Medium, tracked −1.2 %, drawn as outlines (no font needed). Interface and website: Inter.
Licence: SIL Open Font Licence — free for logos and commercial use.

## Clear space and size
- Keep clear space around the logo at least the **height of the dot × 2** on every side.
- Minimum size: symbol **16 px** (favicon) / **6 mm** print; horizontal lockup **96 px** / **24 mm** wide.

## Don't
- Don't close the circle, move the dot, or rotate the mark.
- Don't recolour outside the palette, add gradients to the flat mark, or outline it.
- Don't put the glow on light backgrounds or stretch / squash any version.
- Don't retype "Zen Sync" in another font next to the symbol — use the lockup files.

## Before launch
Run a UK trademark search for "Zen Sync" (IPO) and check the domain you'll use; the mockups show zensync.com only as a placeholder.
